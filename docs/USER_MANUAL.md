# คู่มือการใช้งาน Exam Grader (Teacher & User Manual)

เอกสารฉบับนี้เป็นคู่มือมาตรฐานสำหรับการใช้งานโปรแกรม **Exam Grader** ซอฟต์แวร์ตรวจข้อสอบปรนัยจากภาพกระดาษคำตอบแบบ **Offline 100%** สำหรับคุณครูและสถานศึกษา

---

## 1. บทนำและสถาปัตยกรรมความปลอดภัย (Overview & Security)

Exam Grader ถูกออกแบบขึ้นเพื่อแก้ปัญหาความล่าช้าและลดภาระงานตรวจข้อสอบของคุณครู โดยยึดหลักการความปลอดภัยสูงสุด:

- **100% Offline Processing:** รูปภาพกระดาษคำตอบ ข้อมูลนักเรียน และผลคะแนน ประมวลผลบนเครื่องคอมพิวเตอร์ของคุณครูทั้งหมด ไม่มีการส่งข้อมูลใด ๆ ออกสู่อินเทอร์เน็ตหรือ Cloud Server
- **Human-in-the-Loop:** โปรแกรมจะไม่เดาคำตอบแทนครูเมื่อพบกรณีภาพไม่ชัดเจน ลบไม่สะอาด หรือฝน 2 ข้อ แต่จะแยกข้อที่กำกวมออกมาให้คุณครูตรวจทานและยืนยันด้วยตนเอง
- **Preserve Original Evidence:** บันทึกรูปภาพกระดาษคำตอบต้นฉบับคู่กับผลการตรวจ พร้อมภาพหลักฐานที่มีรอยวงเฉลยสีเขียว/แดง เพื่อความโปร่งใสสามารถตรวจสอบย้อนหลังได้

## 3. ขั้นตอนการติดตั้งและการเปิดใช้งานครั้งแรก (Installation)

### สำหรับผู้ใช้ macOS
1. ดาวน์โหลดไฟล์ `Exam-Grader-v*.dmg` จาก [GitHub Releases](https://github.com/bithope21/exam-grader/releases) หรือ [bithope.app/exam-grader](https://bithope.app/exam-grader)
2. ดับเบิลคลิกไฟล์ `.dmg` และลากไอคอน **Exam Grader** ไปยังโฟลเดอร์ **Applications**
3. **การเปิดใช้งานครั้งแรก (Gatekeeper Security):**
   - หากระบบแจ้งเตือนว่า *"Exam Grader cannot be opened because it is from an unidentified developer"*
   - ให้เปิด **System Settings** → **Privacy & Security** เลื่อนลงมาที่หัวข้อ Security แล้วกดปุ่ม **Open Anyway**
   - หรือคลิกขวาที่ไอคอนโปรแกรมในโฟลเดอร์ Applications แล้วเลือก **Open**

### สำหรับผู้ใช้ Windows
1. ดาวน์โหลดไฟล์ `Exam-Grader-v*-Windows-Setup.exe`
2. ดับเบิลคลิกเพื่อติดตั้งและทำตามคำแนะนำบนหน้าจอจนเสร็จสิ้น
3. **การเปิดใช้งานครั้งแรก (SmartScreen Security):**
   - หาก Windows Defender SmartScreen แสดงหน้าต่างสีฟ้า
   - ให้คลิกที่ข้อความ **More info (ข้อมูลเพิ่มเติม)**
   - จากนั้นคลิกปุ่ม **Run anyway (เรียกใช้ต่อไป)**

## 4. มาตรฐานการเตรียมและพิมพ์กระดาษคำตอบ (Answer Sheet Best Practices)

ความถูกต้องแม่นยำในการตรวจ OMR ขึ้นอยู่กับคุณภาพของกระดาษคำตอบ:

1. **การพิมพ์:**
   - ใช้กระดาษ A4 สีขาวมาตรฐาน ความหนา 70–80 แกรม
   - **ต้องสั่งพิมพ์ที่ขนาดจริง 100% (Actual Size)** เสมอ *ห้ามเลือก Fit to page หรือย่อ/ขยาย* เพื่อรักษาสัดส่วนระยะห่างของมาร์กเกอร์ทั้ง 4 มุม
2. **มาร์กเกอร์สี่เหลี่ยมสีดำทั้ง 4 มุม (Alignment Markers):**
   - ต้องพิมพ์ออกมาดำสนิท คมชัด ครบทั้ง 4 มุม
   - ห้ามเจาะรูทับมาร์กเกอร์ ห้ามมีรอยพับ รอยฉีกขาด หรือคราบหมึกเลอะบนมาร์กเกอร์
3. **คำแนะนำสำหรับการฝนของนักเรียน:**
   - แนะนำให้ใช้ดินสอดำความเข้ม 2B หรือปากกาสีดำ/น้ำเงินเข้ม
   - ฝนให้เต็มวงรี/วงกลม หากต้องการเปลี่ยนข้อ ให้ใช้ยางลบลบรอยเดิมให้สะอาดที่สุด

## 5. คู่มือขั้นตอนการตรวจ 6 ขั้นตอน (Workflow Guide)

### ขั้นตอนที่ 1: สร้างชุดข้อสอบ (Exam Setup)
- เปิดโปรแกรม Exam Grader แล้วกด **"สร้างการสอบใหม่"**
- เลือกแม่แบบกระดาษคำตอบที่ใช้งาน:
  - **Default #1:** แบบมาตรฐาน 60 ข้อ (ตัวเลือก ก ข ค ง จ / A B C D E)
  - **Default #2:** แบบมาตรฐาน 40 ข้อ
  - **Default #3:** แบบมาตรฐาน 30 ข้อ
- ระบุชื่อวิชา รหัสวิชา ชั้นเรียน และคะแนนเต็ม

### ขั้นตอนที่ 2: บันทึกเฉลยคำตอบ (Answer Key)
- คุณครูสามารถป้อนเฉลยได้ 2 วิธี:
  1. **คลิกเลือกเฉลยทีละข้อ** บนหน้าจอโปรแกรม
  2. **สแกนกระดาษเฉลย (Scan Key Sheet):** นำกระดาษคำตอบที่คุณครูฝนเฉลยไว้แล้วมาสแกน โปรแกรมจะบันทึกเป็นเฉลยอัตโนมัติ

### ขั้นตอนที่ 3: นำเข้ารูปภาพกระดาษคำตอบ (Import Images)
- คลิกปุ่ม **"นำเข้ารูปภาพ (Import)"** และเลือกโฟลเดอร์ภาพถ่ายหรือภาพสแกนกระดาษคำตอบของนักเรียน
- รองรับไฟล์สกุล `.jpg`, `.jpeg`, `.png`
- โปรแกรมรองรับการนำเข้าจำนวนมากในคราวเดียว (Bulk Processing) พร้อมระบบ Scaled ECC แคชเพื่อเร่งความเร็วในการตรวจ

### ขั้นตอนที่ 4: การประมวลผลและการปรับระนาบ (Automated Processing)
- ระบบจะตรวจจับมาร์กเกอร์ทั้ง 4 มุม ปรับระนาบภาพที่เอียงให้ตรง (Perspective Homography)
- ตรวจจับความเข้มของรอยฝนในแต่ละข้อเทียบกับกระดาษพื้นหลัง

### ขั้นตอนที่ 5: การตรวจทานโดยครู (Teacher Review & Bulk Edit)
- โปรแกรมจะแสดงสถานะของแต่ละแผ่น:
  - **ผ่าน (Passed):** อ่านรอยฝนครบถ้วนชัดเจน คะแนนคิดอัตโนมัติ
  - **ต้องตรวจทาน (Needs Review):** มีข้อที่กำกวม เช่น ฝน 2 ข้อ, รอยลบไม่สะอาด, หรือรอยฝนจาง
- คุณครูสามารถคลิกดูภาพขยายของข้อที่ต้องสงสัย และคลิกเปลี่ยนคำตอบที่ถูกต้องได้ทันที
- รองรับการเลือกหลายแผ่นพร้อมกันเพื่อแก้ไขสถานะแบบกลุ่ม (Multi-select Bulk Edit)

### ขั้นตอนที่ 6: ส่งออกผลคะแนน (Export Results)
- คลิก **"ส่งออกผลลัพธ์ (Export)"**
- เลือกรูปแบบการส่งออก:
  - **ไฟล์ Excel (.xlsx):** สรุปคะแนนรวม คะแนนรายข้อ สถิติค่าเฉลี่ย/ส่วนเบี่ยงเบนมาตรฐาน
  - **ภาพกระดาษคำตอบที่ตรวจแล้ว (.jpg):** ภาพกระดาษคำตอบที่มีรอยวงเฉลยสีเขียว (ถูก) สีแดง (ผิด) และระบุคะแนนรวมไว้ที่หัวกระดาษ

## 6. การแก้ปัญหาที่พบบ่อย (Troubleshooting & FAQ)

### Q: ทำไมระบบแจ้งว่าหา Marker ไม่พบ (Marker Detection Failed)?
- **สาเหตุ:** ภาพถ่ายไม่เห็นมุม Marker ครบทั้ง 4 มุม, กระดาษพับงอ, แสงสะท้อนจ้าจนมาร์กเกอร์สีขาว, หรือภาพเบลอหลุดโฟกัส
- **วิธีแก้:** ถ่ายภาพใหม่โดยวางกระดาษบนโต๊ะราบเรียบ ให้เห็นขอบกระดาษและ Marker ทั้ง 4 มุมครบถ้วนในเฟรม และหลีกเลี่ยงเงาพาดทับ

### Q: หากนักเรียนใช้ปากกาสีน้ำเงินตรวจได้หรือไม่?
- **ตอบ:** ตรวจได้ครับ แต่แนะนำปากกาหมึกสีเข้ม (น้ำเงินเข้มหรือดำ) และฝนให้เต็มวงรี

### Q: โปรแกรมค้างหรือหน่วงเวลาตรวจภาพจำนวนมาก?
- **ตอบ:** Exam Grader v1.0.1 มีระบบ Fast Scaled Feature Matching ที่เร่งความเร็วขึ้นถึง 4.7 เท่า หากตรวจมากกว่า 200 แผ่น แนะนำให้ปล่อยให้ระบบประมวลผลตามคิวสักครู่หนึ่ง
